# @aegis-initiative/ts-template

Minimal TypeScript package skeleton. Part of the AEGIS repo template.

## Develop

```bash
npm install
npm run build
```

Built output lands in `dist/` and is what gets published to npm.

## Status

Vanilla starting point. AEGIS conventions (exports shape, test runner, publishing workflow, OIDC trusted publisher) will be layered in during the normalization work tracked by [aegis-initiative#30](https://github.com/aegis-initiative/aegis-initiative/issues/30).
