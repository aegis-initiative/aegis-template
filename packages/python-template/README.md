# python-template

Minimal Python package skeleton. Part of the AEGIS repo template.

## Develop

```bash
python -m venv .venv
source .venv/bin/activate   # .venv\Scripts\activate on Windows
pip install -e .
```

## Status

Vanilla starting point. AEGIS conventions (test runner, linter, publishing workflow, DOI minting) will be layered in during the normalization work tracked by [aegis-initiative#30](https://github.com/aegis-initiative/aegis-initiative/issues/30).
