# rust-template

Minimal Rust library skeleton. Part of the AEGIS repo template.

## Build

```bash
cargo build
cargo test
```

## Status

Vanilla starting point. AEGIS conventions (publishing workflow, rustfmt config, clippy rules, crates.io metadata) will be layered in during the normalization work tracked by [aegis-initiative#30](https://github.com/aegis-initiative/aegis-initiative/issues/30).
